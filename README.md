# Olivermontes

Projeto web desenvolvido para a ONG Olivermontes, com o objetivo de apresentar a organização, seus projetos e formas de participação.

## Objetivo

O projeto tem como finalidade disponibilizar uma interface web para apresentação da ONG, permitindo ao utilizador conhecer seus projetos, participar como voluntário, realizar doações e efetuar cadastro.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- JavaScript Modules
- localStorage
- Git
- GitHub

## Funcionalidades

- Navegação entre as seções da aplicação;
- Navegação SPA (Single Page Application);
- Templates JavaScript;
- Formulário de cadastro;
- Validação dos dados preenchidos;
- Máscaras para CPF, telefone e CEP;
- Mensagens de feedback ao utilizador;
- Armazenamento de dados utilizando localStorage.
